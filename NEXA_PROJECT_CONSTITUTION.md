# PROJECT VISION

Nexa Trade Mart is not just an online store.

Our mission is to build Africa's Intelligent Commerce Ecosystem that connects:

• Customers
• Sellers
• Suppliers
• Warehouses
• Delivery Partners
• Commission Partners
• Employees
• AI Departments
• CEO Control Center

Everything must operate as one secure, scalable, intelligent platform.

---

# PROJECT PRINCIPLES

Every change made to this project MUST follow these principles:

1. Never break existing working features.
2. Never remove features unless explicitly requested.
3. Upgrade instead of replacing.
4. Preserve backward compatibility whenever possible.
5. Build modular systems.
6. Build scalable systems.
7. Write clean, maintainable code.
8. Reuse components instead of duplicating code.
9. Prioritize security.
10. Prioritize performance.
11. Prioritize user experience.
12. Think long-term before implementing anything.

---

# DEVELOPMENT RULES

Before making changes:
